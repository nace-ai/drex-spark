## Integration branding

Use **Drex for Apache Spark™** as the integration's display name. The
[Apache Spark trademark guidelines](https://spark.apache.org/trademarks.html) allow the
“for Apache Spark” form and separately allow `spark` in package identifiers; `drex-spark` and
`drex_spark` remain technical identifiers. Use the full Apache Spark name in prominent references,
link to the project, and include attribution on documentation pages that reference it.

## Apache Spark artwork

The [ASF trademark FAQ](https://www.apache.org/foundation/marks/faq/#integrateswith) permits unmodified
project logos to identify software an integration supports, with a project link and trademark attribution,
without implying endorsement. Its [product-branding guidance](https://www.apache.org/foundation/marks/faq/#poweredby)
separately prohibits directly associating ordinary project logos with third-party product logos.

The README therefore keeps the Spark logo in the **Apache Spark integration** section, separate from the
Nace header. It identifies the Apache project, not Drex's own brand. Do not restore the paired-logo header.
Databricks support is described separately and does not imply partnership or endorsement.
